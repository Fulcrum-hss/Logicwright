# CM_Cylinder V0.1.0

`CM_Cylinder` is the first Logicwright standard control module for Siemens TIA Portal projects.

The module is a governed library block, not project-specific generated logic. Logicwright generates project instances, I/O binding, HMI faceplate binding, and alarm mapping from the input package.

Import order:

1. `CM_Cylinder_Types.scl`
2. `CM_Cylinder.scl`
3. Generated project instance and call sources

Scope:

- Single-solenoid and double-solenoid cylinders
- Extend and retract commands
- Manual HMI command interface
- Enable and permit inputs
- Extend and retract timeout monitoring
- Feedback conflict and missing feedback alarms
- Interlock lost and command conflict alarms

Safety logic is not generated by this block.
